# TestFlight に出すまでの手順

ゾーンNOW の iPhone アプリを TestFlight で配るまでの流れです。Mac は要りません。アプリを作ってアップロードするのは GitHub のクラウドの Mac がやります。

※ Apple の画面の名前や場所は変わることがあります。見つからないときは、画面のスクリーンショットを Claude に送ってください。

## 全体の流れ

| # | やること | 誰が | かかる時間 |
|---|---|---|---|
| 1 | Apple Developer Program に登録 | 登録する人（18歳未満なら保護者） | 10分＋Apple の承認待ち |
| 2 | アプリの ID（Bundle ID）を登録 | 登録した人 | 3分 |
| 3 | App Store Connect でアプリを作る | 登録した人 | 5分 |
| 4 | APIキー（アップロード用の鍵）を作る | 登録した人 | 5分 |
| 5 | GitHub に鍵を4つ入れる | あなた | 5分 |
| 6 | GitHub でアップロードを実行 | あなた | ボタン1つ＋約20〜40分 |
| 7 | テスターを招待して、iPhone に入れる | 登録した人／あなた | 10分 |

---

## 1. Apple Developer Program に登録

準備するもの
- 登録する人の Apple アカウント（**2ファクタ認証がオン**、名前は**本名**）
- 年会費の支払い用のカード（年99米ドル。登録画面では円で表示される）

手順
1. iPhone に「**Apple Developer**」アプリ（Apple 公式・無料）を入れる
2. 登録する人の Apple アカウントでサインイン
3. 「アカウント」→「今すぐ登録」
4. 本名（半角ローマ字。例：YAMADA TARO）、住所、電話番号を入れる
5. 規約に同意して、支払う
6. Apple から「ようこそ」のメールが来たら完了（すぐ来ることもあれば、数日かかることもある）

注意
- 登録した人の本名が、App Store で「販売元」として表示されます
- 18歳未満の Apple アカウントでは登録できません（「今すぐ登録」が押せない）

---

## 2. アプリの ID（Bundle ID）を登録

1. ブラウザで https://developer.apple.com/account を開いてサインイン
2. 「**Certificates, Identifiers & Profiles**」→「**Identifiers**」→「＋」
3. 「**App IDs**」→「Continue」→「**App**」→「Continue」
4. 次のとおり入れて「Continue」→「Register」
   - Description：`ZoneNOW`
   - Bundle ID：「**Explicit**」を選び、`jp.zonenow.app`
   - Capabilities：何もチェックしなくてよい

あわせて、**チーム ID** を控える：https://developer.apple.com/account の「**メンバーシップの詳細**（Membership details）」にある、10文字の英数字（例：`AB12CD34EF`）。

---

## 3. App Store Connect でアプリを作る

1. https://appstoreconnect.apple.com を開いてサインイン
2. 「**アプリ**」→「＋」→「**新規アプリ**」
3. 次のとおり入れて「作成」
   - プラットフォーム：**iOS**
   - 名前：`ゾーンNOW`（ほかのアプリと同じ名前は使えない。使えなければ `ゾーンNOW - 勉強ショート` など）
   - プライマリ言語：**日本語**
   - バンドルID：`jp.zonenow.app`（2で登録したもの）
   - SKU：`zonenow001`（自分用の管理番号。何でもよい）
   - ユーザアクセス：**フルアクセス**

---

## 4. APIキー（アップロード用の鍵）を作る

1. App Store Connect の「**ユーザとアクセス**」→「**統合**」（Integrations）タブ →「**App Store Connect API**」
2. 初めてのときは「アクセスをリクエスト」を押して、同意する
3. 「チームキー」の「＋」（キーを生成）
   - 名前：`GitHub`
   - アクセス：**Admin**（証明書を自動で作るのに必要）
4. 次の3つを控える
   - **Issuer ID**（キーの一覧の上に出ている、長い英数字とハイフン）
   - **キー ID**（作ったキーの行にある10文字の英数字）
   - **APIキーのファイル**（「APIキーをダウンロード」で `AuthKey_キーID.p8` が保存される）

⚠️ **APIキーのファイルは1回しかダウンロードできません。** なくしたら、キーを消して作り直します。

⚠️ **APIキーは、チャット（Claude を含む）やLINEに貼らないでください。** このキーがあると、あなたのアプリを勝手にアップロードできてしまいます。入れる場所は GitHub の Secrets だけです。

---

## 5. GitHub に鍵を4つ入れる

1. https://github.com/ryugo201001037-wq/zo-ne-NOW を開く
2. 「**Settings**」→「**Secrets and variables**」→「**Actions**」→「**New repository secret**」
3. 次の4つを、1つずつ作る（Name は大文字・小文字もこのとおりに）

| Name | Secret（中身） |
|---|---|
| `APPLE_TEAM_ID` | 2で控えたチーム ID |
| `ASC_KEY_ID` | 4で控えたキー ID |
| `ASC_ISSUER_ID` | 4で控えた Issuer ID |
| `ASC_KEY_P8` | `AuthKey_キーID.p8` の中身を**全部**（`-----BEGIN PRIVATE KEY-----` の行から `-----END PRIVATE KEY-----` の行まで） |

`.p8` の中身の見方（iPhone の場合）
- 「ファイル」アプリで `AuthKey_….p8` を長押し →「名称変更」で最後を `.txt` に変える → 開く → 全部選んでコピー
- パソコンがあれば、メモ帳などで開いてコピーするほうが確実

Secrets に入れた中身は、入れたあとは誰にも（あなた自身にも）見えません。間違えたら「Update」で入れ直せます。

---

## 6. GitHub でアップロードを実行

1. GitHub の「**Actions**」タブ →左の一覧の「**TestFlightにアップロード**」
2. 「**Run workflow**」→ ブランチは `main` のまま →「Run workflow」
3. 20〜40分ほどで緑のチェックになれば成功。赤い×になったら、その画面のスクリーンショットを Claude に送る
4. 成功してから、Apple 側の処理に10〜30分ほどかかる（終わると Apple からメールが来る）

- 「TestFlightにアップロード」が一覧にないときは、この手順が入った版がまだ main にマージされていない
- アップロードのたびにビルド番号（1, 2, 3…）が自動で増える。バージョン（1.0.0）は `index.html` の `APP_VERSION`

---

## 7. テスターを招待して、iPhone に入れる

**内部テスト（あなたと身近な人、最大100人。Apple の審査なし）**
1. App Store Connect の「**ユーザとアクセス**」で、テスターを「ユーザ」として招待する（役割は「マーケティング」などでよい）。招待された人はメールで承認する
2. アプリの「**TestFlight**」タブ →「内部テスト」の「＋」でグループを作り、テスターとビルドを追加
3. テスターの iPhone に「**TestFlight**」アプリ（Apple 公式・無料）を入れて、招待されたアカウントで開く →「インストール」

**外部テスト（生徒など、最大1万人。簡単な審査あり）**
- アプリの説明、意見の送り先メール、テスト内容などを入れて、ベータ版の審査に出す
- 審査に通ると、**公開リンク**を配るだけで誰でも入れられる
- 外部テストの前に、プライバシーポリシーなどの準備が必要（Claude と相談）

※ 18歳未満の Apple アカウントが内部テスターになれるかは、まだ確かめていません。なれない場合は、外部テストの公開リンクで入れます。

## 保護者の方へ（保護者の名義で登録する場合）

- **何のため**：子どもが作っている勉強アプリ「ゾーンNOW」を、iPhone アプリとしてテスト配布（TestFlight）するためです。Apple のルールで、登録は成人の名義に限られています。
- **費用**：年99米ドル（登録画面で円の金額が表示されます）。自動更新は、Apple アカウントの「サブスクリプション」からいつでも止められます。
- **お願いしたいこと**：上の手順の1〜4です（登録、アプリの ID、アプリの作成、アップロード用の鍵の作成）。合わせて30分ほどで、その後の作業は子どもが GitHub で行います。
- **表示される名前**：App Store の「販売元」に、登録した方の本名が表示されます。
- **お金の動き**：アプリは無料で、アプリ内での課金もありません。
